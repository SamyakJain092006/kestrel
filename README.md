#### Kestrel is a high-frequency trading research stack, built from scratch in C++20. It replays a full day of Nasdaq TotalView-ITCH 5.0 market data and rebuilds the order-by-order (L3) limit order book. It then runs market-making strategies against a deterministic simulated exchange that models feed latency, order latency and exact queue position. The goal is to report two things with equal rigour: the system's latency distribution (p50 to p99.9, measured per component) and strategy P&L under several fill models, with confidence intervals.

##### Status: early development. Results will be added here as each component is built and measured.
